# كويز اللغة القبطية

موقع امتحان في اللغة القبطية. الأسئلة وإجابات الطلبة متخزنة في Supabase،
والموقع نفسه ملفات ساكنة من غير `npm` ولا build.

## تشغيل محلي

```bash
node dev/serve.js
```

وافتح:

| | |
|---|---|
| الامتحان | http://localhost:8000/ |
| الإدارة | http://localhost:8000/pages/admin.html |
| الاختبارات | http://localhost:8000/dev/tests.html |

**لازم سيرفر، مش فتح الملف مباشرة.** من `file://` المتصفح بيمنع الاتصال
بـ Supabase، والصفحة هتوريك تنبيه أحمر بده.

## قبل أي رفع

```bash
node dev/run-tests.js      # اختبارات الدوال
node dev/check-pages.js    # فحص الصفحات
node dev/bump-version.js   # تزويد رقم نسخة الملفات
```

`bump-version` مهم: المتصفح بيحتفظ بالملفات ١٠ دقايق، فممكن يجيب
`index.html` الجديدة ومعاها `script.js` القديم والصفحة تقع. الرقم
(`?v=3`) بيجبره يجيب الملفات الجديدة.

## الاختبارات

```bash
node dev/run-tests.js
```

نفس الاختبارات بتتشغّل في المتصفح من `dev/tests.html`. مفيش مكتبة اختبارات
لأن المشروع من غير `npm` عن قصد.

## الملفات

| المسار | الدور |
|---|---|
| `index.html`, `js/script.js` | الامتحان |
| `pages/admin.html`, `js/admin.js` | صفحة الإدارة |
| `pages/keyboard.html`, `keyboard-alt.html` | الكيبورد القبطي كصفحة مستقلة |
| `js/db.js` | كل التعامل مع Supabase |
| `js/config.js` | رابط Supabase والمفتاح العام |
| `js/lib/quiz-core.js` | دوال خالصة (تحويل الأسئلة، حساب الـ id) — دي اللي متختبرة |
| `js/lib/coptic-markup.js` | فك ترميز `{{ }}` و `(( ))` للخط القبطي |
| `js/lib/coptic-keyboard.js` | الأبجدية وبناء مفاتيح الكيبورد، مشتركة بين الصفحتين |
| `db/schema.sql` | الجداول والصلاحيات — لمشروع Supabase جديد |
| `db/seed-questions.sql` | الـ ١٠٠ سؤال الأصلية |
| `db/fix-attempts.sql` | تعديل اتطبق على المشروع الحالي بعد ما اشتغل |

## الأسئلة

كلها في الداتابيز، بتتضاف وتتعدل من `pages/admin.html`. مفيش ملف أسئلة في
المشروع — النسخة القديمة اللي كانت في `js/questions.js` موجودة في تاريخ git
(`git show 7cf79cc:js/questions.js`).

`id` السؤال شكله `X_XXXX`: الرقم الأول هو النوع (١ أكمل، ٢ اختيار من متعدد،
٣ صح وغلط) والباقي ترقيم متسلسل لكل نوع لوحده. الصعوبة مش داخلة في الرقم عن
قصد، عشان تنقل سؤال بين المستويات من غير ما ترقمه من أول.

## الحماية

الطالب بيدخل من غير تسجيل دخول، وفيه حساب أدمن واحد بس. القواعد كلها في
Postgres نفسها (RLS) مش في كود المتصفح:

- الطالب يقرا الأسئلة النشطة، ويسجل محاولة وإجاباتها. وبس.
- الطالب **ميقدرش** يقرا نتايج حد، ولا يضيف أو يعدل سؤال، ولا يعدل محاولته
  بعد ما بدأت.
- **الدرجة بتتحسب في الداتابيز** من الإجابات المسجلة (العرض
  `attempt_results`)، مش بيبعتها المتصفح. يعني تزوير الدرجة مش ممكن.

المفتاح اللي في `js/config.js` عام ومصمم إنه يبان في المتصفح. **مفتاح
`service_role` ممنوع يتكتب في أي ملف هنا.**
